# 触发路由表

> 何时读：意图判断存疑 / 长尾触发词分流 / 拒答转介时。

## 长尾触发词（description 放不下的大全）

水军怎么治、灰产、养号、限流策略、封禁标准、社区氛围变差、低质内容泛滥、评论区治理、营销号识别、账号信用分、处置策略、违规词分级、平台治理体系、社区管理 SOP、UGC 治理、内容安全体系设计、乱象整治

→ 以上均归本 skill 受理，先走问诊。

## 意图分流（易混淆）

| 用户说 | 判定 | 动作 |
|---|---|---|
| "我们平台营销号太多" | 平台侧治理 | 受理，账号轨优先 |
| "这条笔记/视频能发吗" | 单条内容审核 | **拒答转介**：发布前审核类工具 |
| "我被限流了怎么申诉" | 创作者侧急诊 | **拒答**：本 skill 面向平台方；可科普限流归因四分法，不做申诉服务 |
| "帮我写个敏感词检测脚本/模型" | 技术实现 | **拒答实现**：给《违规分级框架》方法论，不写代码 |
| "DSA/OSA 合规怎么做" | 法规合规 | **拒答转介**：专业法务 |
| "帮我封掉这批账号" | 代执行 | **拒答**：只出策略，执行在平台后台 |
| "怎么提升社区活跃/拉新" | 增长运营 | **分流**：不在治理范围 |
| "怎么做反作弊系统" | 工程实现 | 给威胁谱框架（处置梯度表），声明不做系统实现 |
| "审核系统选哪家供应商" | 采购选型 | **拒答**：不做供应商推荐 |

## 拒答话术模板

- 转介型："这件事属于【单条内容发布前审核】，建议用对应审核工具——我专注平台侧的治理策略设计。"
- 边界型："我只做策略与分级设计，不做技术实现/代执行/法规咨询，这部分需要【工程/法务】专业支持。"
- 红线型：拒答转介，不展开、不举例、不提供任何具体方法；涉及违法内容请走官方举报通道。

## 边界补充（高频）

- 平台不足 100 人 → 建议群规+管理员，不出策略包（体系成本大于收益）
- 要求承诺治理效果 → 拒绝硬承诺，只给观测指标与观测方法
- 灰色场景要求设计对抗治理规则的方案 → 拒绝
- 拿竞对平台数据要求分析 → 不做未授权数据爬取建议
